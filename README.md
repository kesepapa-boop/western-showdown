# western-showdown
シャープMZ-700用ゲームです。要PCG700

過去の記憶を頼りにタイトーのWestern gunをモチーフとしたゲームを作ってみました。

MZT形式です。エミュ、実機両方で実行できると思います。

１．遊び方
カウボーイを4方向キーで移動させ、銃を撃って相手のカウボーイを倒してください。

基本二人用対戦ゲームですが、VS CPU用も付けました。ただしランダムに移動、乱射します。

・得点：1回倒すと2点

・制限時間：９０秒間

・勝敗：スコアの高い方が勝ちです。引き分けもあります。

・移動：方向キーでカウボーイを動かします。

・射撃：3方向（斜め上、前、斜め下）のどれかを決めて射撃します。

    ただし画面上には自分の弾丸は1つしか表示されません。消えるまで次は撃てません。

・岩：弾丸が当たると跳弾します。真っすぐ撃った場合、岩の上半分は４５度斜め上、下半分は４５度斜め下に飛びます。

・サボテン：当たると消えます。弾丸も消えます。

２．操作方法

キーボード及び、ジョイスティックが使用可能です。

（１）キーボード

 必ず最初にメニューの「2」キーを押してキー設定することをお勧めします。

 UP,DOWN,LEFT,RIGHT,AIM(銃の方向）,FIRE（射撃）の６つのキーを設定してください。
 
 なお1Pと2Pのキーの重複識別はしていませんので同じキーを割り当てるとゲームになりません(笑)

 ・UP,DOWN,LEFT,RIGHT：その通りカウボーイが上下左右に移動します。同時押しで斜め移動も可能です。

 ・AIM：銃の方向。押すたびに方向が変わります。斜め上->正面->斜め下->正面->斜め上・・・

 ・FIRE：射撃

（２）ジョイスティック

 ・方向：カウボーイ移動。斜めに入れると斜め移動可能です。

 ・Aボタン：射撃

 ・Bボタン：銃の方向
